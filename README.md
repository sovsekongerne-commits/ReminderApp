# Sted & Påmindelse

Huskesedler og indkøbslister, der dukker op, når du **ankommer** til et sted.

## Hent appen
Gå til **Releases** og hent den nyeste `sted-og-paamindelse.apk` på telefonen.

GitHub bygger appen automatisk ved hver ændring (se fanen **Actions**).
Android-mappen genereres under bygget; tilpasninger ligger i `android_overrides/`.
